# Greenhouse model

Export from Blender as **glTF Binary** (`.glb`):

- Apply scale/rotation before export
- Y-up, modest poly count
- Optional: name bed meshes `bed_1`, `bed_2`, `bed_3` for click mapping later

Save as `greenhouse.glb` in this folder, then set `USE_GLB = true` in `src/scene/GreenhouseScene.tsx`.
